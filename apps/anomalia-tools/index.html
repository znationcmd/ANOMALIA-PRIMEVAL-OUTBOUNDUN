Plugin Unreal Engine 5 — compilation native

Génère un véritable plugin .uplugin et son module C++, puis lance RunUAT BuildPlugin sur un PC Windows équipé d'Unreal Engine. Ne compile pas les ressources 3D, ne monte pas le plugin dans le jeu et ne publie rien automatiquement.

La compilation exécute du code C++ du projet local. N'utilise ce bouton que pour un projet que tu considères fiable. Le chargement dans ANOMALIA nécessite encore un système de mods côté jeu.

ANOMALIA / UTILITAIRES

Utilitaires

Fonctions natives Unreal et outils de compatibilité clairement identifiés.

Terrain Processor

Traitement réel des heightmaps PNG dans Content/Terrain.

Crée un nouveau PNG, conserve la source.

BankRev — compatibilité

Le format PBO propriétaire de DayZ n’est pas extrait par ANOMALIA Tools. Aucun résultat fictif.

Image To PAA — alternative Unreal

Unreal Engine utilise notamment TGA et PNG, pas les textures PAA de DayZ.

Cfg Convert — configuration

Conversion réelle de la syntaxe INI/CFG et des objets JSON locaux en JSON ANOMALIA. Les CFG binaires DayZ ne sont pas pris en charge.

DS Utils — sécurité

Les signatures DayZ BISIGN et le format PBO ne sont pas compatibles avec les plugins Unreal. Les manifestes SHA-256 ne sont pas des signatures numériques.

Tex View — ANOMALIA

Le visualiseur local existe déjà dans Texture Tools pour PNG, JPG et WebP.

Nav Mesh Generator — UE5

La génération d’un NavMesh natif doit être exécutée dans Unreal Engine, pas simulée dans une interface.

Dans le niveau Unreal, placer un Nav Mesh Bounds Volume, couvrir les surfaces accessibles, construire la navigation, puis tester les IA. Pour les ponts réparables, actualiser les données de navigation.

Sélectionne un projet pour utiliser les conversions.
