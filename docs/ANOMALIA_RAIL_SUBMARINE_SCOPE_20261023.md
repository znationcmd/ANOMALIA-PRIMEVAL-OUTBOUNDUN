# ANOMALIA — scoped vehicles and rail candidates (2026-10-23)

## Explicitly excluded by project owner
Do not research, import, commission or implement: combine harvesters (moissonneuses), forage harvesters (ensileuses), agricultural sprayers (pulvérisateurs), ferries, cargo ships, oil tankers, fishing trawlers, tugboats or container ships. Preserve any existing files/features; exclusion is from new scope, **not authorization to delete**.

## Retained priorities
1. Fully functional submarines with enterable interiors, ballast/dive, air/oxygen, depth, damage, sonar and underwater world integration.
2. Realistic snowmobiles, with ski steering and tracked propulsion, seated players, cold biome traction.
3. Trains, locomotives, passenger coaches, freight wagons (not container ships), rails, switches, signals, stations, tunnels, coupling and multiplayer synchronization.
4. Metro trains, multi-car sets, underground stations, tunnels, passenger access and doors.
5. Tramways, buses/coaches and emergency/special-purpose road vehicles.
6. Existing requested cars, motorcycles, military vehicles, helicopters, planes, yachts, zodiacs, jet skis and naval vessels remain in scope.

## Integration acceptance criteria
Each model must be individually checked for provenance, download rights, game-use license, attribution, textures, topology, cockpit/interior, separate movable parts, scale, collisions, LODs and performance. No third-party binary committed to public GitHub without redistribution rights. Existing ANOMALIA UE 5.8 game code, saves, branches and assets must remain untouched unless changes are safe and reviewed. No model is marked integrated until a working UE editor scene, movement, physics, multiplayer and packaged Windows build have been tested.
