# ANOMALIA — Hybrids and Moro-inspired creatures

New registries: `dino_moro_creatures_catalog.json` (13 entries, one cosmetic skin) and `dino_hybrid_breeding.json`.

**Status: configuration only, not operational in Unreal Engine.** Existing creature and taming catalogs are preserved.

Normal reproduction allows same-species and cross-variant breeding; genetic-lab hybridization is designed to allow cross-species offspring with parent DNA, inheritance, incubation, per-server compatibility rules, tameability and saddle riding. Wild hybrid spawning is disabled until assets and balancing exist. All new creature spawns are disabled until original meshes, animations and AI exist. The skeletal Moro Rex is a cosmetic variant, not an extra biological species.

Implementation: add Unreal authoritative genetics, cross-species compatibility matrix, creature model and animation variants, species saddle sizing and riding, AI and taming, incubation, persistent genealogy, server-config loaders, validation and multiplayer tests. Original assets only; third-party mod names are reference requests, not permission to redistribute mod content.
