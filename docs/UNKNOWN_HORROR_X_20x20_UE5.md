# UNKNOWN HORROR X — 20 × 20 km

Nouvelle carte ANOMALIA’Z PRIGIMALIA indépendante de SKARVIK et RACCONIA-VARKOVIA.

* Superficie totale : **400 km²**.
* **80 % terre = 320 km²**; **20 % eau = 80 km²**.
* Développement souterrain cible : **80 % des terres = 256 km² de secteurs planifiés** (la surface est simplement réservée; tunnels non excavés).
* 5 lignes de métro et 26 stations, 12 sites souterrains, 8 lieux de surface, 18 chemins et routes.

## Livrable généré

Archive `UNKNOWN_HORROR_X_20x20_UE5_SOURCE.zip` transférée dans Google Drive `ANOMALIAZ_PRIGIMALIA`, comprenant le terrain R16 1025, masques terre/mer et occupation souterraine, plan PNG, JSON des routes/métros/sites, script Python de **marqueurs** pour éditeur UE5 et guide.

Les fichiers ont été créés hors Unreal Engine ; **aucun vrai niveau World Partition, aucune ligne de métro, aucun intérieur souterrain ni jeu UE5 fonctionnel n'a été créé par cette modification**. La prochaine étape consiste à importer les données et modéliser les secteurs/tunnels dans le vrai `D:\ANOMALIA`.
